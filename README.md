# Gesttack ERP

ERP system focused on commercial management, inventory control and sales operations.

## Technologies

- Java
- PostgreSQL
- SQL
- Spring Boot (in progress)
- React / Angular (planned)

## Features

- Product management
- Category, type and brand control
- Inventory management
- Stock movement history
- Sales and sales items
- Recipe and ingredient management

## Database Modeling

The project was modeled using relational database concepts with:

- Primary Keys (PK)
- Foreign Keys (FK)
- One-to-One relationships
- One-to-Many relationships
- Many-to-Many relationships
